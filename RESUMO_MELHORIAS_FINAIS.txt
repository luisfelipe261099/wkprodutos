🎯 OBJETIVO

Melhorar a experiência do usuário ao trabalhar com orçamentos que possuem
muitos itens (50+), adicionando funcionalidades de edição e rolagem.

════════════════════════════════════════════════════════════════════════════

✨ FUNCIONALIDADES ADICIONADAS

1. ✅ ROLAGEM NA TABELA
   ├─ Altura máxima: 600px
   ├─ Overflow automático
   ├─ Cabeçalho fixo (sticky)
   ├─ Scrollbar customizada
   └─ Suporta 50+ itens sem problemas

2. ✅ BOTÃO EDITAR
   ├─ Abre modal para editar quantidade
   ├─ Mostra produto, quantidade atual, preço
   ├─ Subtotal atualiza em tempo real
   ├─ Validação de quantidade
   └─ Salva alterações facilmente

3. ✅ BOTÃO REMOVER
   ├─ Remove item da tabela
   ├─ Total recalcula automaticamente
   ├─ Ícone visual (lixo)
   └─ Feedback imediato

════════════════════════════════════════════════════════════════════════════

📊 ANTES vs DEPOIS

ANTES:
├─ Tabela sem limite de altura
├─ Página crescia indefinidamente
├─ Sem opção de editar quantidade
├─ Apenas botão "Remover"
└─ Difícil trabalhar com 50+ itens

DEPOIS:
├─ Tabela com rolagem (max-height: 600px)
├─ Página mantém tamanho consistente
├─ Botão "Editar" com modal
├─ Botão "Remover" com ícone
├─ Cabeçalho fixo durante rolagem
└─ Fácil trabalhar com 50+ itens
