║                              RESUMO DO FLUXO                                   ║
╠════════════════════════════════════════════════════════════════════════════════╣
║                                                                                ║
║  1. Usuário acessa /system                                                    ║
║  2. .htaccess redireciona para index.php                                      ║
║  3. index.php verifica se está logado                                         ║
║  4. Se logado → dashboard.php                                                 ║
║  5. Se não logado → login.php                                                 ║
║  6. Usuário faz login                                                         ║
║  7. Credenciais verificadas                                                   ║
║  8. Se válidas → sessão criada → dashboard.php                                ║
║  9. Se inválidas → erro exibido → login.php                                   ║
║  10. Usuário pode acessar todas as páginas protegidas                          ║
║  11. Logout destrói sessão → login.php                                        ║
║                                                                                ║
