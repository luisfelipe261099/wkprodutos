┌────────────────────────────────────────────────────────────────────────────────┐
│ COMO USAR                                                                      │
└────────────────────────────────────────────────────────────────────────────────┘

1. BUSCAR POR NOME
   └─ Digite o nome do produto no campo de busca
   └─ Pressione Enter ou aguarde 500ms
   └─ Resultados aparecem com paginação atualizada

2. BUSCAR POR SKU
   └─ Digite o código SKU no campo de busca
   └─ Exemplo: "SKU123"

3. BUSCAR POR FORNECEDOR
   └─ Digite o nome do fornecedor no campo de busca
   └─ Ou use o dropdown "Fornecedor"

4. COMBINAR FILTROS
   └─ Selecione um fornecedor no dropdown
   └─ Digite um termo de busca
   └─ Ambos os filtros são aplicados

5. NAVEGAR PÁGINAS
   └─ Clique em "<<" para ir à primeira página
   └─ Clique em ">>" para ir à última página
   └─ Clique nos números para ir a uma página específica

6. LIMPAR BUSCA
   └─ Clique no botão "X" ao lado do campo de busca
   └─ Volta para a página 1 sem filtros
